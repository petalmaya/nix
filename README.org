#+TITLE: Nixtop – NixOS Flake

* Overview

This is the reworked configuration (v2) – flat module tree by concern.

- =flake.nix= is the entry point. =nixosConfigurations.wonderland/rabbit/garden= are the hosts.
- =hosts/<host>/{default.nix,disko.nix,hardware-configuration.nix}= is host policy.
- =modules/default.nix= exports =nixosModules= and =homeModules=; edit there to add/remove a module.
- =modules/core= is the system baseline (bootloader, networking, sops, zram/zswap, pipewire, fonts, greetd selector, sddm/apparmor/maintenance, cachix/plymouth/nix-ld/podman, zsh/tmux).
- =modules/browsers= is per-browser config (chromium, firefox), enabled per user.
- =modules/user/<name>/{home.nix,flatnix.nix}= are per-user profiles (alice+lewis on wonderland, lewis on rabbit, rose on garden).
- =modules/mango= is MangoWC config: shared base (=config,settings,layout,rules,animations=) + per-shell variants (=appearance,keybinds,autostart=) selected by =nixtop.shell=.
- =modules/matugen= owns colour generation from wallpaper at runtime; it writes a Noctalia palette bridge (=~/.config/noctalia/palettes/nixtop.json=), JES colors (=~/.local/state/JES_colors.json=), and app configs. See =modules/matugen/templates=.
- Shells are selected per user by =nixtop.shell = "noctalia" | "quickshell" | "jes" | "none"= (host default =none=, waybar-only): =modules/shell/noctalia=, =modules/shell/quickshell= (own nixtop-shell), =modules/shell/jes= (vendored fork). The greeter follows =nixtop.greetd.greeter=.
- Theming ownership is switchable: =nixtop.theme.owner = "auto" | "matugen" | "noctalia"= (default =auto= follows shell) plus per-app =nixtop.theme.apps.<app>=.

* Prerequisites

- Nix with =nix-command= + =flakes= enabled.
- A sops age key at =/var/lib/sops-nix/keys.txt= matching =.sops.yaml= (see =secrets/secrets.yaml.example=).

* Quick start

#+BEGIN_SRC sh
nix flake check --no-build
nix build .#nixosConfigurations.wonderland.config.system.build.toplevel
sudo nixos-rebuild switch --flake .#wonderland
#+END_SRC

On first install for =garden=, generate hardware config:

#+BEGIN_SRC sh
nixos-generate-config --show-hardware-config > hosts/garden/hardware-configuration.nix
#+END_SRC

=garden= ships a placeholder =hardware-configuration.nix= until then, so
=nix build .#garden= is expected to fail before the laptop is installed.

Secrets are managed by sops-nix: =secrets/secrets.yaml= is tracked in git
sops-encrypted (decryptable only on machines holding the age key); see
=secrets/secrets.yaml.example=, =.sops.yaml=.

* Wallpaper → theme

#+BEGIN_SRC sh
nixtop-theme ~/Pictures/Wallpapers/your.jpg
# or via the shell's wallpaper picker (quickshell) – both run matugen and nudge Noctalia + Mango.
#+END_SRC

* Dev live-edit flags (opt-in, default off except emacs)

- =nixtop.dev.liveEmacs= (default on) – =~/ .config/emacs= → repo =modules/emacs/emacs=
- =nixtop.dev.liveMango= – =~/ .config/mango= → repo =modules/mango=
- =nixtop.dev.liveMatugen= – =~/ .config/matugen/templates= → repo =modules/matugen/templates=
- =nixtop.dev.liveQuickshell= – =~/ .config/nixtop-shell= → repo =modules/shell/quickshell/shell=
- =nixtop.dev.liveSway= – =~/ .config/sway= → repo =modules/sway/sway=
- =nixtop.dev.liveMako= – =~/ .config/mako= → repo =modules/sway/mako=
- =nixtop.dev.liveWaybar= – =~/ .config/waybar/config= → repo =modules/sway/waybar/config.jsonc= (config only; =style.css= stays matugen-owned)

Editing a template with the flag off = rebuild.

* Layout

#+BEGIN_SRC text
flake.nix
├── hosts/wonderland, rabbit, garden
├── modules/
│   ├── default.nix          # nixosModules / homeModules lists
│   ├── core/                # NixOS baseline + greetd/sddm selector + cachix/plymouth/nix-ld/podman/apparmor/maintenance + zsh/tmux (HM)
│   ├── browsers/            # chromium, firefox
│   ├── conf/                # foot, fetch, yazi, gtk
│   ├── emacs/               # vendored emacs tree (GPL) + live-editable config
│   ├── mango/               # shared + variants/noctalia|quickshell
│   ├── matugen/             # templates + palette bridge + nixtop-theme CLI
│   └── shell/               # noctalia/ + quickshell/ + jes/ (vendored, see NOTICE.md)
├── assets/greeter, font, boilers (future dev-shell templates)
└── secrets/
#+END_SRC
