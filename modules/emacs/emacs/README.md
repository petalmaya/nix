# Flutter Emacs

An Emacs configuration that lives in a Nix flake. It is a **fork of
[Centaur Emacs](https://github.com/seagle0128/.emacs.d) v8.3.1**
(GPL-3.0) — every Centaur module is vendored in `vendor/centaur/lisp/`
— re-branded, re-themed, and wired into this flake. See
[`NOTICE.md`](NOTICE.md) and [`vendor/centaur/NOTICE.md`](vendor/centaur/NOTICE.md).

## Layout

```
~/.config/emacs/            symlink → modules/home/apps/emacs/emacs
├── init.el                 entry point: Elpaca bootstrap + module loading
├── early-init.el           startup perf, frame, transparency
├── lisp/
│   ├── my-elpaca.el        Elpaca bootstrap (package manager)
│   ├── init-extras.el      QML + media extras (empv/ement/elcord), nix-mode
│   └── init-ewm.el         EWM compositor config (dormant in nested emacs)
├── vendor/centaur/lisp/    the absorbed Centaur modules (init-*.el)
├── themes/pinaceae-theme.el  your theme, generated by matugen
├── custom-example.el       template copied to custom.el on first run
├── custom.el               customize settings (generated, gitignored)
├── custom-post.el(.org)    your personal overrides (optional, gitignored)
├── eshell/alias            eshell aliases
└── elfeed/                 your elfeed database (tracked)
```

## Package management

Packages are installed by **Elpaca** (git-based, async) — not by Nix.
On first launch Elpaca clones and builds everything; subsequent
launches are incremental. Update packages with `M-x update-packages`
(→ `elpaca-update-all`). The whole Elpaca tree lives in
`~/.config/emacs/elpaca/` and is gitignored.

## Theming

The `pinaceae` theme (`themes/pinaceae-theme.el`) is generated by
matugen from your wallpaper (see `modules/home/services/matugen` in
this flake) and written straight into this directory — regenerate it
and reload with `M-x flutter-load-theme` (or `F6` → Theme → pinaceae,
or `M-x consult-theme`). The Centaur doom-themes stack was removed
deliberately.

## Key features (all of Centaur, minus the branding)

- Completion: vertico (vertical minibuffer list) + orderless fuzzy
  matching + marginalia/consult/corfu. `M-x` (also on `C-x C-m`) gets
  the vertical fuzzy list; set `flutter-completion-style` to
  'childframe with `M-x customize` for Centaur's floating posframe look.
- Terminal: ghostel on `C-c t` (+ `project-prefix-map` `m`/`M`, popterm
  `C-`` backend); see `vendor/centaur/lisp/init-shell.el`.
- EWM compositor (`lisp/init-ewm.el`, compositor-only — a nested `emacs`
  stays a plain editor): Wayland apps as buffers when `nixtop.ewm.enable`
  is on — `s-d` consult launcher with XDG apps (`a SPC` narrows),
  `s-<return>` ghostel, `s-f` fullscreen, `s-S-SPC` float, `s-TAB` next
  surface, `s-t`/`s-n` new frame, `s-q`/`s-S-q` close buffer/frame,
  `s-w` jump windows, `s-l` lock, pamixer/brightnessctl media keys,
  `C-c e` EWM hydra (frames, windows, lock, outputs,
  wallpaper picker), window rules, `ctrl:nocaps` xkb to match the OS.
  The dashboard opens on the first compositor frame; switch wallpapers
  with `M-x flutter-ewm-set-wallpaper`. Enable per-user + pick the
  `ewm` session at login; Noctalia stays untouched.
- Editing: expand-region, multiple-cursors, iedit, hungry-delete,
  smartparens, avy, vundo, drag-stuff, …
- UI: doom-modeline, dashboard (F2), which-key, solaire-mode, hydras
  (F6 toggles, `C-c m` media), treemacs, tabspaces workspaces
- Programming: eglot LSP, dape debugger, gptel AI, tree-sitter,
  apheleia formatting, devdocs, quickrun
- Languages: c/c++, go, rust, python, ruby, elixir, web/js/css, org,
  markdown, docker, nix, QML (Quickshell — this repo's quickshell/)
- Reading/media: elfeed, newsticker, nov (epub), pdf-view, bongo/mpd
  clients, empv (mpv), ement (Matrix), elcord (Discord presence)
- Extras: org-roam, pomidor, wgrep, ztree, ibuffer, dired-hacks,
  Chinese calendar/dict/pinyin (kept from upstream), proxy toggles

## Notes

- External tools (language servers, debuggers, formatters, mpv, docker,
  …) come from the flake — see `default.nix`'s `externalTools`.
- `flutter-player` is on by default (MPD runs on the hosts). Disable it
  in `custom.el` if you don't want the mpd clients.
- Missing server binaries (e.g. `fish-lsp`) just mean eglot won't start
  for those languages — add the package to `externalTools` if you need
  it. grip-mode needs `pkgs.grip`; pdf-view needs pdf-tools built
  (toolchain already in `externalTools`).
- eglot/eldoc/flymake/jsonrpc/xref use Emacs 30's built-in copies (a
  matched set; Elpaca only installs third-party packages). To force a
  newer eglot, add `(elpaca (eglot :repo "https://github.com/joaotavora/eglot"))`
  to `my-elpaca.el` — the built-in deps are already version-ignored.
- Completion stays in the minibuffer: Centaur's floating childframe
  style is off by default (`flutter-completion-style` in
  `vendor/centaur/lisp/init-custom.el`); flip it to 'childframe with
  `M-x customize` for the posframe look.
- To debug startup: `emacs -Q -l ~/.config/emacs/init-mini.el`, or run
  `emacs --debug-init`.
